# Demo Lab Evidence Record integration

These 390 × 844 WebKit captures verify that canonical Demo Lab fixtures open
the merged production Evidence Record in each supported disclosure state.

1. `01-evidence-record-summary.png` — both primary disclosures collapsed
2. `02-evidence-record-reasoning-expanded.png` — plain-language reasoning open
3. `03-evidence-record-full-technical-expanded.png` — full record and technical
   metadata open

The captures use canonical redness fixture A and contain synthetic data. They
are generated by:

```sh
CAPTURE_DEMO_LAB_EVIDENCE=true npx playwright test e2e/demo-lab.spec.ts \
  --project=mobile-webkit
```

The Demo Lab does not duplicate Evidence Record markup. Each image is rendered
by the production `EvidenceRecord` component and
`evidenceRecordViewModelFromRecord`.
